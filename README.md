# LOKO RUSH · ФК Локомотив Київ

3D-футбол для браузера (ПК і телефон, горизонтально, на весь екран). Vite + Three.js + чистий JavaScript.
Усі моделі, текстури й звуки створюються в коді: у проєкті немає жодного `.glb`, `.png` чи `.mp3`.

## Запуск

```bash
npm install
npm run dev      # розробка
npm run build    # збірка в dist/ (≈167 КБ gzip разом із кодом)
```

## Керування

- Притисни палець чи мишу біля м'яча й відтягни назад: з'явиться пунктир з відскоками від бортів і ударами по гравцях.
- Відпусти, і виконавець б'є. Довжина відтягування задає силу.
- Низька сила — це пас: твій партнер прийме м'яч, і цілитися можна вже від нього.
- `Esc` чи `P` — пауза, `F` — повний екран.

## Правила

- Матч 75 с, нічия — золотий гол. Годинник іде в темпі гри.
- 11 на 11: розстановки 4-4-2, 4-3-3, 4-2-3-1. Лінії зсуваються за м'ячем, суперник опікує, пресингує й віддає передачі.
- Режим володіння: щойно м'яч у тебе, час сповільнюється (×0,2) до удару або до відбору. Найближчий суперник біжить на тебе, кільце навколо м'яча червоніє, чим він ближче. Коли він добіг, відбір вдається з імовірністю 60–90 % (залежить від ліги), інакше його «оглушує» на мить.
- Після удару темп повертається. Твій гравець приймає м'яч повторно — режим вмикається знову.
- Суперник, який відібрав м'яч, веде його, віддає пас або б'є по воротах. Твої гравці можуть відібрати м'яч назад.
- Гравці й м'яч тверді: ніхто не проходить крізь іншого. Сильний удар проходить між своїми гравцями, слабкий — це пас.
- Анімації: біг із кроком за швидкістю, нахили в поворотах, ведення з підбиттям м'яча, закритий корпус під тиском, прийом ногою чи грудьми, підкат, заточування при втраті м'яча, сейви воротаря з ковзанням і кидок руками, святкування гуртом: автор голу біжить до кута й ковзає на колінах, партнери збігаються до нього.
- Рикошет: гол після 2 і більше відскоків від борту множить монети.

## Мета-гра

- Ліги: Друга → Перша → УПЛ → Ліга чемпіонів, потім новий сезон із сильнішими суперниками.
- «Удар» (сила) і «Стадіон» (дохід): картки внизу меню.
- Команда: у кожного з 11 гравців власні навички й рівень. Швидкість, удар, пас, дриблінг, відбір, інтелект (у воротаря реакція, дотяжка, ловля). Вони реально впливають на гру й ШІ, а розвиваються досвідом за дії в матчі (гол, пас, відбір, сейв) і тренуванням за монети. Суперники теж мають особисті навички, що ростуть із лігою; у HUD видно картку гравця з м'ячем.
- Трансфери: нападники (точність і довжина прицілу) та воротарі.
- Академія: випускник кожні кілька матчів; найкращий виходить на поле.
- Стадіон еволюціонує на острові: трибуни, прожектори, другий ярус, дах із табло, прапори, золота арена.
- Каса стадіону копичить монети, поки тебе немає (до 90 хв).
- Прогрес зберігається в `localStorage`.

## Структура

```
src/main.js            точка входу
src/config.js          константи, ліги, розстановки, трансфери
src/core/              гра, цикл, стейт-машина (MENU/MATCH/GOAL/RESULT), звук, камера
src/graphics/          воксельні гравці, поле, борти, трибуни, острів, м'яч, частинки
src/physics/           м'яч, колізії, приціл з відскоками
src/match/             правила, команди й ШІ (розстановка, пресинг, пас), сцена матчу
src/ui/                HUD, меню, трансфери, академія, результат (HTML/CSS)
src/state/             збереження й економіка
```

## Оптимізація

- Статична геометрія зливається в один меш із вершинними кольорами (запечений AO знизу кожного куба).
- Гравець — 5 мешів і один спільний матеріал: обличчя й номери беруться з одного UV-атласу.
- 22 м'які тіні одним `InstancedMesh`; глядачі (~1300) двома `InstancedMesh`; частинки — пул без алокацій.
- Динамічних тіней немає; у циклі кадру немає `new` та `for…of` по гарячих масивах.
- Фізика з фіксованим кроком 120 Гц, приціл симулюється тим самим кодом, що й справжній удар.
- Динамічна роздільність (Авто / Висока / Економна в налаштуваннях) тримає ~60 fps.
- Камера слідує за м'ячем, видно ~60 одиниць поля; під час прицілу плавно віддаляється.
- Повний екран і блокування орієнтації запитуються після першого дотику; у портретному режимі показується підказка повернути пристрій, матч ставиться на паузу.
- Манифест PWA (`display: fullscreen`, `orientation: landscape`) і сервіс-воркер для офлайну (на HTTPS).

## ФК Локомотив Київ у грі

Факти взято з відкритих джерел: [Вікіпедія](https://en.wikipedia.org/wiki/FC_Lokomotyv_Kyiv), [Kyiv Post](https://www.kyivpost.com/post/76681), [Еспресо](https://espreso.tv/kultura-z-nagodi-100-richchya-stadionu-lokomotiv-u-kievi-yakiy-torik-znishchila-rf-klub-ogolosiv-pro-rekonstruktsiyu).
Дані про емблему та форму в текстових джерелах відсутні, тому значок у грі стилізований (сигнальні прапорці й колесо), а не офіційний логотип. Усе зібрано в `src/club.js`.

- Клуб заснований 1919 року як «Залдор», прізвисько «залізничники», скорочено ЛОКО; власник: Південно-Західна залізниця.
- Червоний і зелений узято із залізничної сигналізації: червоний — стоп, зелений — вперед. У грі це семафор у HUD (зелений: м'яч у нас, червоний: у суперника), зелені «рейки» на футболці, червоно-зелені трибуни й рекламні борти зі словами ЛОКО, СТОП, ВПЕРЕД.
- Стадіон «Локомотив»: відкрито 2 серпня 1925 року, 1631 місце. Вивіска на станції острова, довідка й факти про ракетний удар 2024 року та сторіччя 2025.
- «Хроніка клубу»: 13 сторінок історії від 1919 до виходу до Першої ліги 2026; нова сторінка відкривається за кожну перемогу.
- «Символіка»: кольори, прізвисько, нагороди (5 титулів чемпіона Києва, група Б Другої ліги 2025–26), легенди й вихованці клубу.
- Шлях у грі збігається з реальним: Друга ліга → Перша ліга → УПЛ → Ліга чемпіонів. Девіз на старті матчу: «Локо рухається вперед» (слова президента Олександра Єгорова, не офіційний слоган).
