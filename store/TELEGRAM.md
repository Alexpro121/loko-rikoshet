# Випуск LOKO RUSH у Telegram

Код уже готовий до запуску як Mini App (`src/core/telegram.js`). Лишились кроки, які може зробити лише власник бота.

## 1. Опублікувати збірку

Telegram відкриває гру за HTTPS-адресою. Підходить чинний GitHub Pages, окремий хостинг не потрібен:

```text
https://alexpro121.github.io/loko-rikoshet/
```

Пуш у `main` публікує збірку автоматично. Поки зміни не на сайті, у Telegram відкриється стара версія без інтеграції.

## 2. Створити бота й Mini App

У [@BotFather](https://t.me/BotFather):

1. `/newbot`: назва `LOKO RUSH`, username на вибір, наприклад `loko_rush_bot`. Токен нікому не передавай: він іде лише в `/etc/loko-game/env` на сервері гри (`BOT_TOKEN`), і сервер сам налаштує команди, описи, кнопку «Грати» й вебхук (`server/README.md`, «Бот гри»).
2. Аватар бота: `public/icon-512.png`.
3. `/mybots` → бот → **Bot Settings** → **Configure Mini App** → **Enable Mini App**, адреса з кроку 1. Там же можна задати кольори й значок заставки: колір гри `#0b3d2a`.
4. Опис і короткий опис сервер ставить сам (`server/src/bot/texts.js`); тексти нижче — для ручного варіанта без сервера.
5. `/setinline` → підказка `код кімнати`: так у чатах працюють картки виклику (`@бот`), а «Посилання» в лобі шле картку через вікно «Поділитися».

Якщо BotFather зараз називає пункти інакше, іди за його підказками.

Посилання на гру буде таким: `https://t.me/USERNAME?startapp`. Окремий застосунок із власною назвою робить `/newapp`, йому знадобиться обкладинка 640×360: `store/telegram-cover-640x360.png`. Основного Mini App для випуску достатньо.

## 3. Увімкнути запрошення через Telegram

Заміни `BOT_LINK` на початку `src/core/telegram.js`:

```js
const BOT_LINK = 'https://t.me/USERNAME';
```

Запрошення з кнопки «Посилання» в лобі тоді відкриє кімнату прямо в Telegram (`?startapp=room_КОД`). Поки рядок порожній, запрошення веде на сайт гри, і друг заходить у браузері; матч теж працює.

## 4. Перевірити на справжніх пристроях

Без Telegram цього не перевірити, тож пройди список до анонсу:

- [ ] iPhone і Android: гра відкривається на весь екран, після повороту лишається горизонтальною.
- [ ] Кнопки Telegram угорі не закривають рахунок, паузу й меню.
- [ ] Свайп пальцем у матчі не згортає гру; «назад» закриває вікно або ставить паузу.
- [ ] Закриття посеред матчу просить підтвердження.
- [ ] Згортання в матчі ставить паузу, звук вимикається; після повернення все продовжується.
- [ ] Вібрація працює на iPhone.
- [ ] Прогрес лишається після **Налаштування → Дані та пам'ять → очищення кешу** і з'являється на другому пристрої.
- [ ] Онлайн-матч між двома телефонами за посиланням-запрошенням.
- [ ] Telegram Desktop: вузьке вікно показує підказку, «На весь екран» запускає гру.
- [ ] Частота кадрів на слабкому Android: у вебв'ю вона може бути нижчою, ніж у браузері.

Як дивитись консоль: Android, WebView Debug у налаштуваннях Telegram і `chrome://inspect/#devices`; iOS, «Allow Web View Inspection» і меню Develop у Safari; Telegram Desktop Beta, «Enable webview inspection» в експериментальних налаштуваннях.

## 5. Що варто знати

- **Поворот.** Гра йде лише горизонтально. Якщо на телефоні заблоковано автоповорот, Telegram екран не поверне, і гравець побачить підказку вимкнути блокування. Примусово повернути картинку можна лише окремою доробкою вводу.
- **Емблема й імена.** Каталог Telegram публічний. Як і для Google Play, потрібна письмова згода клубу на емблему й імена гравців (`store/PLAY_STORE.md`, розділ «Юридичне»).
- **Політика конфіденційності:** `https://alexpro121.github.io/loko-rikoshet/privacy.html`, розділ про Telegram уже є.
- **Рейтинг і монети** живуть на пристрої гравця, сервера немає, тож їх можна підробити. `initData` гра не перевіряє: для цього потрібен сервер із токеном бота. Якщо з'являться таблиці лідерів чи платежі в Stars, спершу потрібен бекенд.
- **Два пристрої одночасно.** Перемагає копія, записана останньою; незбережене на іншому пристрої замінюється на наступному запуску.
