# Випуск LOKO RUSH у Google Play

## 1. Хостинг
TWA вимагає HTTPS-домен із `/.well-known/assetlinks.json` у корені.
GitHub Pages із підшляхом `/loko-rikoshet/` не підходить. Варіанти:
- власний домен, привʼязаний до GitHub Pages (Settings → Pages → Custom domain), або
- репозиторій `alexpro121.github.io` (корінь), або Netlify/Cloudflare Pages.
Після деплою мають відкриватися:
`https://ДОМЕН/manifest.webmanifest`, `https://ДОМЕН/privacy.html`, `https://ДОМЕН/.well-known/assetlinks.json`.
Для Vite з коренем домену збірка вже використовує `base: './'`.

## 2. Збірка .aab
```bash
npm i -g @bubblewrap/cli
# замініть ВАШ_ДОМЕН у twa-manifest.json, потім:
bubblewrap init --manifest=https://ВАШ_ДОМЕН/manifest.webmanifest
bubblewrap build        # створить app-release-bundle.aab (+ запросить пароль keystore)
```
Потрібні JDK 17 та Android SDK (Bubblewrap запропонує завантажити).
**Збережіть `loko-rush.keystore` і пароль у надійному місці.**
Альтернатива без командного рядка: https://www.pwabuilder.com → Package for Stores → Android.

## 3. assetlinks.json
У Play Console: Setup → App signing → скопіюйте **SHA-256** сертифіката підпису застосунку
і вставте у `public/.well-known/assetlinks.json` (замість заповнювача), задеплойте сайт.
Без цього зверху буде адресна стрічка Chrome.

## 4. Play Console
1. Акаунт розробника ($25). Нові особисті акаунти: верифікація + закрите тестування 12 тестувальників × 14 днів.
2. Створіть застосунок: «Гра», безкоштовна. Package: `com.lokorush.game`.
3. Завантажте `.aab` у Closed testing → потім Production.
4. Store listing: тексти нижче, іконка `public/icon-512.png`, feature graphic `store/feature-graphic-1024x500.png`,
   щонайменше 2 скриншоти (ландшафт, напр. 1920×1080; зробіть у грі: меню, матч, пенальті, стадіон).
5. Privacy policy URL: `https://ВАШ_ДОМЕН/privacy.html`.
6. Data safety: «Дані не збираються і не передаються».
7. Content rating (IARC): футбольна аркада, без насильства, → 3+/Everyone.
8. Ads: «Немає реклами». Target audience: 13+ (щоб уникнути вимог Families).

## 5. Юридичне
Гра використовує емблему та імена гравців ФК «Локомотив Київ». Перед публікацією
отримайте письмову згоду клубу або замініть лого/імена на вигадані — інакше можливе блокування за скаргою.
У тексті лістингу вказано, що проєкт фанатський і неофіційний.

## 6. Оновлення
Контент гри оновлюється деплоєм сайту. Нова версія в Play потрібна лише при зміні
обгортки (піднімайте `appVersion` у twa-manifest.json на +1).
